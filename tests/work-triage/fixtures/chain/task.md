Create a four-beat short film. Each beat is generated from the end frame of the one before; generation is paid and the user approves the first take. Helper scripts have selftests that can use dummy clips.

1. Write the shot list and prompts for all four beats.
2. Generate beat 1 (paid); the user approves the take.
3. Generate beat 2 from beat 1's end frame.
4. Generate beat 3 from beat 2's end frame.
5. Generate beat 4 from beat 3's end frame.
6. Write a script that extracts a clip's last frame and checks its size, with a selftest.
7. Collect sound references for the four beats.
8. Write a script that joins four clips, with a selftest on dummy clips.
9. Join the real clips and check the cut.
